# Local telemetry acceptance (M02.03)

This is a synthetic, explicitly started process resource only. Install the exact lock with `npm ci --ignore-scripts`. Start with `aspire run --apphost apphost.cs` using the pinned CLI and trusted local developer TLS certificate. Verify the frontend requires login and the HTTP OTLP listener is loopback-only. Start the synthetic-shadow resource, inspect the STOPPED fixture, and check the dashboard for service softwarefactory-shadow, span factory.evaluate, factory.stage.count and factory.stage.duration metrics, and factory.stage.completed structured log correlated with its trace/span ID. Stop the AppHost with Ctrl+C or `aspire stop --apphost apphost.cs`. Never bypass TLS or publish raw exports, resource env or tokens. 

The SDK consumes AppHost-provided OTEL_EXPORTER_OTLP_ENDPOINT, OTEL_EXPORTER_OTLP_PROTOCOL and OTEL_EXPORTER_OTLP_HEADERS. Missing or unsupported configuration fails closed. HTTP/protobuf only; no remote destination, no live provider, no default collector. If the AppHost supplies gRPC or a nonnumeric hostname, correct the local endpoint configuration rather than allow remote export. The SDK tests exercise real OTLP receipt at a synthetic loopback receiver; dashboard acceptance is separate. Capture exact candidate runtime evidence on Linux and Windows, including dashboard-side trace, metrics and correlated logs. Do not close #17 solely because the process or synthetic receiver succeeds.

References: https://aspire.dev/app-host/configuration/ and https://aspire.dev/dashboard/apis/ .

Shutdown regression tests use the real pinned HTTP/protobuf exporters against authenticated synthetic loopback receivers returning HTTP 400 or leaving requests unanswered. Each signal must attempt export; the work result must remain unchanged and provider shutdown must settle within the 10-second regression bound (3-second configured exporter timeout, with scheduling margin). Exporter failure may be reported through SDK diagnostics or an explicit aggregate cleanup error; neither is proof of dashboard receipt. The separate in-flight observation drain has a 3-second limit.

The SDK rejects a nonempty NODE_TLS_REJECT_UNAUTHORIZED override before loading any exporters, including for loopback HTTPS. Use a trusted development CA through NODE_EXTRA_CA_CERTS, not a TLS verification bypass. The negative test verifies the disabled-verification configuration cannot construct exporters or send an API key.

For continuously streaming collector responses, the pinned exporter inactivity timeout alone is insufficient. Its supported custom HTTP agent factory applies a three-second absolute deadline to each request and destroys the request when the deadline expires, with TLS verification explicitly enabled and no keep-alive or proxy agent. The regression suite includes all three signals against a continuously streaming authenticated receiver and checks that the receiver sees each connection close as well as bounded shutdown. The ten-second test bound allows scheduling margin; passing transport tests are not dashboard persistence evidence.
