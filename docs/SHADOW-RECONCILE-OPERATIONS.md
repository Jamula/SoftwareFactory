# Default-off event-driven inventory (#5, #6, #10)

This is an intermediate read-only self-pilot listener. Its inventory responds to issue changes, target-branch PR changes, selected CI completions, and manual requests. Manual dispatch is restricted to refs/heads/main; the job refuses other branch or tag refs. The inventory uses a trusted main checkout and bounded public issue and PR reads. Git credentials are never persisted. The listener reports incomplete evidence and has no dispatch or merge operations. Review-completion coverage, trusted policy retrieval, complete evidence normalization, durable event deduplication and loss/restart recovery remain open.

Inventory is default-off unless the repository variable FACTORY_SHADOW_ENABLED is exactly lowercase true. The job-level expression is a coarse filter; a case-sensitive Bash check before checkout gates all remaining steps. Mixed-case values may start the guard but cannot check out code or run inventory. Activation requires independent security review, confirmation of main protection and included capacity, and separately verified owner authorization. Disable by removing or setting the variable false; cancel any already-running read-only job if required. GitHub concurrency serializes active jobs but can replace pending runs; inventory is a fresh reconciliation rather than an event ledger. Durable idempotency remains outstanding. Do not claim an unattended issue-to-merge cycle or two-minute target from this workflow.

Before enablement verify the current workflow revision and its permissions, runner availability, read-only network behavior and actual event coverage. Demonstrate live inventory with zero mutation, capture actual event-to-inventory latency and failures, then proceed to trusted review/check normalization and a separately authorized protected integration path. Never add PR-controlled checkout, artifacts, commands, secrets or privileged token permissions to this workflow.

The PR identity path requires both `FACTORY_SHADOW_ENABLED=true` and `FACTORY_PULL_EVENT_SHADOW_ENABLED=true` as case-sensitive opt-ins. It runs only on `pull_request_target`, checks out the immutable workflow commit from protected `main`, and passes the event's PR number and head SHA as environment values. The adapter checks the workflow identity, checkout SHA and repository ID before reading only that PR with an unauthenticated GitHub GET. It rejects fork PRs, moved heads, mismatched identities, missing data, stale reads and ambiguous rate or permission errors. Its output contains identifiers, state, draft status and elapsed adapter time. Event-to-decision timing needs a separate delivery timestamp. Reconciliation returns incomplete shadow evidence and provides no review, check or merge authorization. The workflow leaves both opt-ins under owner control.
