# Default-off event-driven inventory (#5, #6, #10)

This is an intermediate read-only self-pilot listener. It reacts to issue changes, target-branch PR changes, selected CI completions, and manual requests. Manual dispatch is restricted to refs/heads/main; the job refuses other branch or tag refs. It checks out only the protected main branch, passes no event text or untrusted artifacts to commands, does not persist Git credentials, and reads only the existing bounded public issue/PR inventory. It neither dispatches nor merges, and the inventory explicitly reports incomplete evidence. Review-completion coverage, trusted policy retrieval, complete evidence normalization, durable event deduplication and loss/restart recovery are not implemented by this slice.

Inventory is default-off unless the repository variable FACTORY_SHADOW_ENABLED is exactly lowercase true. The job-level expression is a coarse filter; a case-sensitive Bash check before checkout gates all remaining steps. Mixed-case values may start the guard but cannot check out code or run inventory. Activation requires independent security review, confirmation of main protection and included capacity, and separately verified owner authorization. Disable by removing or setting the variable false; cancel any already-running read-only job if required. GitHub concurrency serializes active jobs but can replace pending runs; inventory is a fresh reconciliation rather than an event ledger. Durable idempotency remains outstanding. Do not claim an unattended issue-to-merge cycle or two-minute target from this workflow.

Before enablement verify the current workflow revision and its permissions, runner availability, read-only network behavior and actual event coverage. Demonstrate live inventory with zero mutation, capture actual event-to-inventory latency and failures, then proceed to trusted review/check normalization and a separately authorized protected integration path. Never add PR-controlled checkout, artifacts, commands, secrets or privileged token permissions to this workflow.
