3-Stage Consumer Onboarding Journey (tools/engineering-factory/consumer-onboarding.mjs):
1. Stage 0 — Read-Only Discovery (<=5 min, <=5 mandatory settings):
   1 natural-language request -> repository, repositoryId, pinnedFactorySha,
   stackProfile (+ optional stricterCoverageThresholds) -> emits 2 files
   (.github/workflows/softwarefactory-shadow-replay.yml and
   .github/softwarefactory-policy.json) with 0 overwritten files, 0 competing
   backlogs (GitHub Issues sole backlog), 0 external services, and $0 spend.
2. Stage 1 — Disabled-at-Rest Shadow PR (<=15 min, STAGE_1_SHADOW_ONBOARDED):
   Dual 40-hex workflow + checkoutRef SHA pins verified, mode: "disabled" +
   killSwitch: true, stricter local gates preserved (>=95%/90% floor or stricter
   existing gates), formal APPROVED review (allowCommentedBotApproval: false),
   isolated repo-read-only-shadow credentialId (sharedAdminToken: false), $0
   AI-credit/Actions overage hard-stops, all 6 mandatory single-mutation shadow
   denials proven (staleReview, dismissedReview, commentedBotReview,
   wrongRepository, missingQuota, killSwitchPolicy), and 1-commit independent
   rollback verified (verifyIndependentRollback).
3. Stage 2 — First Unattended @copilot Merge (STAGE_2_AUTONOMOUS_ACCEPTED):
   Requires Stage 1 plus a non-synthetic (synthetic: false) receipt bound to the
   exact consumer repositoryId proving >=1 bounded unattended @copilot
   (copilot-swe-agent[bot]) issue landed on the healthy protected default branch
   with 0 human interventions, 0 unauthorized writes, 0 production deployments,
   and $0 incremental billed spend.

Public vs. Private Execution Matrix & Billing Hard-Stops (#105):
- Public, private, and internal repositories: gh-aw compiled .lock.yml +
  @copilot (copilot-swe-agent[bot]) + GitHub Actions Automode / pinned
  @microsoft/copilot-sdk 2.0.3 supported.
- Private and internal repositories only: Repository Cloud Automations supported
  (not available on public repositories).
- All visibilities require verified provider-level $0 overage hard-stops (1 AI
  credit = $0.01) across AI Credits, Copilot Premium Requests, and Cloud
  Sandboxes/Actions, zero personal PATs in Actions secrets, and non-estimated
  quota admission checks (gh-aw max-ai-credits caps are soft caps only).
